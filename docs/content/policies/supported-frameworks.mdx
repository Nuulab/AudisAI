# Supported Frameworks

AudisAI supports a growing list of regulations and standards.

## Laws & Regulations

| Code | Region | Law / Act | Description |
| :--- | :--- | :--- | :--- |
| `eu` | European Union | **EU AI Act** | Comprehensive risk-based regulation for AI systems. |
| `tx` | Texas | **HB 149** | Responsible AI Governance Act. |
| `co` | Colorado | **SB 205** | Consumer protections against AI discrimination. |
| `ut` | Utah | **SB 149** | Artificial Intelligence Policy Act (Disclosure). |
| `tn` | Tennessee | **ELVIS Act** | Protection against unauthorized voice/likeness usage. |
| `il` | Illinois | **HB 3773** | AI in employment and hiring. |
| `nyc` | New York City | **Local Law 144** | Bias audits for automated employment decision tools. |
| `ca` | California | **SB 243** | Bot transparency and disclosure requirements. |

## Industry Standards

| Code | Framework | Description |
| :--- | :--- | :--- |
| `nist-ai` | NIST | **AI Risk Management Framework (AI RMF 1.0)** | Guidelines for managing risks in AI systems. |
| `nist-csf` | NIST | **Cybersecurity Framework 2.0** | Standards for cybersecurity related to AI. |
| `iso27001` | ISO/IEC | **ISO 27001:2022** | Information security management systems. |
| `cis` | CIS | **Critical Security Controls v8** | Prioritized safeguards to mitigate cyber attacks. |
